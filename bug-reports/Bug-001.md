# BUG-001 - Toys category displays products from Audio category

## Severity
Medium

## Priority
High

## Environment
- Browser: Chrome Version 155.0.8059.40
- OS: Windows 11 Home x64
- Page: Main page

## Steps to reproduce
1. Open the Demo Shop main page.
2. Select the "Toys" category.
3. Check the displayed products.

## Expected result
Only products belonging to the "Toys" category should be displayed.

Expected products:
- RC Drone Mini
- Kids Robot Toy

## Actual result
"Toys" category also displays products that belong to the "Audio" category:

- Premium Headphones
- Bluetooth Speaker
- Wireless Earbuds S1
