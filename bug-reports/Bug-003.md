# BUG-003 - Last Name input field allows more than 30 characters

## Severity
Medium

## Priority
Medium

## Environment
- Browser: Chrome Version 155.0.8059.40
- OS: Windows 11 Home x64
- Page: Checkout

## Steps to reproduce
1. Open the Demo Shop main page.
2. Add any product to the cart.
3. Proceed to Checkout.
4. Locate the "Last Name" field.
5. Enter more than 30 characters into the field.
6. Check whether the field prevents entering additional characters.

## Expected result
"Last Name" input field should allow a maximum of 30 characters, according to the functional requirements.

The user should not be able to enter more than 30 characters.

## Actual result
"Last Name" input field allows the user to enter more than 30 characters.

Other checkout fields correctly limit the number of entered characters, but the "Last Name" field does not enforce the 30-character limit.
