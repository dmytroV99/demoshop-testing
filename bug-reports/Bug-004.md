# BUG-004 - Phone country code is editable and is not automatically restored when changing country

## Severity
Medium

## Priority
High

## Environment
- Browser: Chrome Version 155.0.8059.40
- OS: Windows 11 Home x64
- Page: Checkout

## Steps to reproduce
1. Open the Demo Shop main page.
2. Add any product to the cart.
3. Proceed to Checkout.
4. Locate the "Phone Number" field.
5. Select "Czech Republic" as the country.
6. Check the country phone prefix.
7. Try to edit or delete the displayed +420 prefix.
8. Delete the +420 prefix completely.
9. Change the selected country to another country.
10. Check the phone prefix.

## Expected result
The phone country code should be automatically controlled by the selected country.

The user should not be able to freely edit or remove the country code.

When the selected country is changed, the corresponding phone country code should be automatically displayed.

For example:
- Czech Republic → +420
- Changing to another country → corresponding country prefix should be automatically displayed.

## Actual result
The country phone code can be manually edited or deleted.

After deleting the +420 prefix and changing the selected country, the new country phone code is not automatically displayed.

Entering a long value into the country code field also causes the phone number section to extend significantly to the right and affects the layout.
