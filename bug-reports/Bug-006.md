# BUG-008 - FLAT20 discount applies $200 instead of $20

## Severity
High

## Priority
High

## Environment
- Browser: Chrome Version 155.0.8059.40
- OS: Windows 11 Home x64
- Page: Checkout

## Steps to reproduce
1. Open the Demo Shop main page.
2. Add any product to the cart.
3. Proceed to Checkout.
4. Enter FLAT20 in the "Special Offer Code" field.
5. Check the discount message and Order Summary.

## Expected result
The FLAT20 discount should apply a fixed discount of $20 to the entire order.

For example, for a $150.00 order:
- Subtotal: $150.00
- FLAT20 discount: $20.00
- Total: $130.00

## Actual result
The system applies a $200 discount instead of the required $20 discount.

The message displayed below the discount code field is:

"Flat $200 Discount Applied!"
