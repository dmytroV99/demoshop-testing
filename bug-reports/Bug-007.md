# BUG-007 - Description field is incorrectly marked as required

## Severity
Medium

## Priority
Medium

## Environment
- Browser: Chrome Version 155.0.8059.40
- OS: Windows 11 Home x64
- Page: Admin Panel
- Function: Create/Edit Product

## Steps to reproduce
1. Open the Demo Shop Admin Panel.
2. Click "Add Product" or open an existing product for editing.
3. Locate the "Description" field.
4. Leave the "Description" field empty.
5. Try to create or update the product.

## Expected result
The "Description" field should be optional.

A product should be possible to create or update without entering a description, according to the functional requirements.

## Actual result
The "Description" field is marked with an asterisk (*), indicating that it is required.

The application requires the user to provide a description even though the functional requirements define Description as an optional field.
